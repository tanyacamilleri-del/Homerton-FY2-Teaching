# Homerton FY2 Teaching – Combined Website

This release is a **single self-contained index.html file** combining 27 original imaging/ECG cases and 40 clinical knowledge questions.

## Replace on GitHub
1. Open https://github.com/tanyacamilleri-del/Homerton-FY2-Teaching
2. In the repository root, open `index.html` and select the pencil (Edit this file).
3. Open the downloaded `index.html` on your computer in a text editor, select all, and copy.
4. Replace all text in the GitHub editor with the new file content, then click **Commit changes**.
5. Wait a few minutes and refresh the GitHub Pages website (hard-refresh if the old version is cached).

**Do not delete any other files.** The new index.html embeds its CSS, case data, JavaScript and clinical quiz. It does not require an assets folder to run. Existing files may remain in the repository.

The images and ECGs remain sourced from Wikimedia Commons and require internet access. If an external image URL is unavailable, the original site's source-link fallback is preserved.

For FY2 education only; clinical content should be reviewed locally before use.
